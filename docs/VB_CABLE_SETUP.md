# VB-CABLE 设置指南 - 解决无声问题

## 🎯 问题说明

使用 VB-CABLE 时，将系统播放设备设为"CABLE Input"后，**默认情况下听不到声音**。

这是因为：
- 音频被路由到虚拟设备 CABLE Input
- 程序从 CABLE Output 捕获音频
- 但音频没有输出到物理扬声器/耳机

---

## ✅ 推荐解决方案：Windows "侦听此设备"功能

**优点**：
- ✅ 零延迟
- ✅ 无回声
- ✅ Windows 原生功能，稳定可靠
- ✅ 音质无损
- ✅ 一次设置，永久生效

---

## 📋 详细设置步骤（Windows 10/11）

### 方法1：通过声音设置（推荐）

1. **打开声音控制面板**
   - 右键点击任务栏右下角的**音量图标** 🔊
   - 点击 **"声音设置"** 或 **"打开声音设置"**
   - 在设置页面中，点击 **"声音控制面板"**（或"相关设置"下的"声音控制面板"）

2. **找到 CABLE Output 设备**
   - 切换到 **"录制"** 标签页
   - 找到 **"CABLE Output (VB-Audio Virtual Cable)"**
   - 如果看不到，右键空白处，勾选 **"显示禁用的设备"** 和 **"显示已断开的设备"**

3. **启用"侦听此设备"**
   - 右键点击 **"CABLE Output"**
   - 选择 **"属性"**
   - 切换到 **"侦听"** 标签页
   - ✅ 勾选 **"侦听此设备"**
   - 在 **"播放通过此设备"** 下拉菜单中，选择你的**物理扬声器/耳机**
   - 点击 **"应用"** → **"确定"**

4. **测试**
   - 将系统默认播放设备设为 **"CABLE Input"**
   - 播放任何音频/视频
   - 你应该能从扬声器/耳机听到声音 🎵

---

## 🖼️ 设置示意图

```
系统音频播放
    ↓
CABLE Input (虚拟播放设备)
    ↓
CABLE Output (虚拟录音设备)
    ↓
    ├─→ 字幕程序捕获 → 生成字幕
    └─→ Windows "侦听" → 物理扬声器/耳机 → 你听到声音
```

## 🎛️ 高级设置（可选）

### 调整侦听延迟

如果觉得有轻微延迟（通常 < 50ms）：

1. 在 CABLE Output 属性中，切换到 **"高级"** 标签页
2. 取消勾选 **"允许应用程序独占控制此设备"**
3. 设置默认格式为 **"16位，16000 Hz"**（与程序采样率匹配）

### 调整音量

- CABLE Output 的音量滑块控制侦听音量
- 不影响程序捕获的音频

## ⚠️ 常见问题

### Q1: 侦听选项是灰色的，无法勾选

**原因**：CABLE Output 设备被禁用

**解决**：
1. 在"录制"标签页中
2. 右键 CABLE Output → **"启用"**
3. 再次打开属性，侦听选项应该可以勾选了

---

### Q2: 勾选后仍然没有声音

**检查项**：
1. 确认"播放通过此设备"选择的是正确的扬声器/耳机
2. 确认该扬声器/耳机没有被禁用
3. 确认系统默认播放设备设为 "CABLE Input"
4. 尝试调高 CABLE Output 的音量

---

### Q3: 有回声/双重播放

**原因**：
- 可能同时启用了程序内播放功能（`ENABLE_PLAYBACK=true`）
- 或者没有将系统播放设备设为 CABLE Input

**解决**：
1. 检查 `.env` 文件，确保 `ENABLE_PLAYBACK=false`
2. 确认系统默认播放设备是 "CABLE Input"，而不是你的物理扬声器

---

### Q4: 想要在不使用字幕程序时关闭侦听

**解决**：
- 不用每次都去设置里改
- 只需将系统播放设备改回你的物理扬声器即可
- 侦听功能仍保持开启状态，但不会工作（因为没有音频进入 CABLE）

## 🔄 切换播放设备的快捷方式

### 方法1：任务栏快速切换（Windows 11）

1. 点击任务栏音量图标
2. 点击右侧的 **">"** 展开播放设备列表
3. 选择 CABLE Input 或你的扬声器

### 方法2：使用快捷键工具（推荐）

安装 **SoundSwitch**（免费开源）：
- 下载：https://soundswitch.aaflalo.me/
- 设置快捷键（如 `Ctrl+Alt+F12`）一键切换
- 显示OSD提示当前设备

## 🎬 使用流程

### 开始使用字幕程序：

1. 按快捷键或手动切换播放设备为 **"CABLE Input"**
2. 运行字幕程序 → 开始捕获
3. 播放视频/音频
4. ✅ 听到声音 + ✅ 看到字幕

### 停止使用：

1. 停止字幕程序
2. 切换播放设备回 **"扬声器/耳机"**
3. 音频恢复正常

---

## 💡 为什么不使用程序内播放？

程序内播放（`ENABLE_PLAYBACK=true`）的缺点：
- ❌ 有延迟（50-200ms）
- ❌ 可能有回声
- ❌ 占用额外CPU资源
- ❌ 音频需要解码再编码

Windows "侦听此设备"的优点：
- ✅ 零延迟（内核级直通）
- ✅ 无回声
- ✅ 零CPU开销
- ✅ 音质无损

---

使用 VB-CABLE + Windows "侦听此设备"是最佳组合：

|------|------|
| 音频捕获 | VB-CABLE |
| 音频播放 | Windows 侦听功能 |
| 字幕生成 | 本程序 |
