# 本地模型与API选择功能指南

## 📖 功能概述

从本版本开始，字幕系统支持两种转录模式：

| 模式 | 描述 | 优点 | 缺点 | 适用场景 |
|-----|------|------|------|---------|
| **API模式** | 使用 OpenAI Whisper API | ✅ 无需本地资源<br>✅ 转录质量稳定<br>✅ 无需下载模型 | ❌ 需要网络连接<br>❌ 按量付费<br>❌ 数据上传到云端 | 网络稳定、注重便利性 |
| **本地模式** | 使用 faster-whisper 本地模型 | ✅ 完全离线运行<br>✅ 免费使用<br>✅ 数据隐私保护<br>✅ 速度更快(有GPU时) | ❌ 需要下载模型<br>❌ 占用本地资源<br>❌ 首次使用较慢 | 离线环境、长时间使用 |

---

## 🚀 快速开始

### 1. 安装依赖

```bash
# 安装所有依赖（包括本地模型支持）
pip install -r requirements.txt

# 如果只需要 API 模式，可以不安装 faster-whisper
# 但建议安装完整依赖以支持两种模式
```

### 2. 启动程序

```bash
python app/main.py
```

### 3. 在GUI中选择模式

程序启动后，在"🤖 转录模式"卡片中选择：

- **☁️ API模式 (在线)**: 使用 OpenAI API
- **💻 本地模式 (离线)**: 使用本地 faster-whisper 模型

**本地模式**下还可以选择模型大小：
- `tiny` - 39M参数，最快，精度较低
- `base` - 74M参数，快速，精度适中 ⭐**推荐**
- `small` - 244M参数，中等速度，精度良好
- `medium` - 769M参数，较慢，精度很好
- `large-v2` - 1550M参数，最慢，精度最佳

## 🎯 本地模型详细说明

### 模型性能对比

| 模型大小 | 参数量 | 显存需求 | 相对速度 | 推荐使用场景 |
|---------|--------|---------|---------|-------------|
| tiny | 39M | ~1GB | ~32x | 实时字幕，对精度要求不高 |
| base | 74M | ~1GB | ~16x | **日常使用，推荐** |
| small | 244M | ~2GB | ~6x | 追求更好精度 |
| medium | 769M | ~5GB | ~2x | 专业翻译，高精度需求 |
| large-v2 | 1550M | ~10GB | ~1x | 最高精度，有GPU加速 |

> 注：速度倍数是相对于实时音频的处理速度（例如 16x 表示处理1小时音频只需约3.75分钟）

### 首次使用

**首次使用本地模式时，程序会自动下载模型：**

1. 选择"本地模式"和模型大小（如 `base`）
2. 点击"开始捕获"
3. 等待模型下载（只需一次，后续无需下载）

**下载位置**: `~/.cache/whisper/`

**下载大小**：
- tiny: ~75MB
- base: ~145MB
- small: ~488MB
- medium: ~1.5GB
- large-v2: ~3GB

### GPU 加速

本地模式支持 GPU 加速，可大幅提升处理速度：

#### 检测当前配置
```python
import torch
print(f"CUDA 可用: {torch.cuda.is_available()}")
print(f"CUDA 版本: {torch.version.cuda}")
```

#### 安装 GPU 版本 PyTorch

**CUDA 11.8**:
```bash
pip install torch --index-url https://download.pytorch.org/whl/cu118
```

**CUDA 12.1**:
```bash
pip install torch --index-url https://download.pytorch.org/whl/cu121
```

安装后重启程序，系统会自动检测并使用 GPU。

#### GPU vs CPU 性能对比

| 模型 | CPU (i7-12700) | GPU (RTX 3060) | 提升倍数 |
|------|---------------|---------------|---------|
| base | ~8x 实时 | ~50x 实时 | 6.25x |
| medium | ~2x 实时 | ~15x 实时 | 7.5x |
| large-v2 | ~0.5x 实时 | ~8x 实时 | 16x |

## 🔧 配置说明

### .env 配置文件

```bash
# ===== 转录模式配置 =====
WHISPER_MODE=api              # api 或 local
LOCAL_MODEL_SIZE=base         # tiny/base/small/medium/large-v2

# ===== API 配置（仅 API 模式需要）=====
OPENAI_API_KEY=sk-xxxxx      # OpenAI API Key

# ===== DeepL 配置（两种模式都需要）=====
DEEPL_API_KEY=xxxxx          # DeepL API Key
```

### GUI 配置（推荐）

建议直接在 GUI 中选择模式，无需修改配置文件：
- 程序会记住您的选择
- 可随时切换模式，无需重启
- 更直观的参数说明

## 💡 使用建议

### 场景1: 日常学习看视频
**推荐**: 本地模式 + base 模型
- 免费无限使用
- 精度足够日常使用
- 速度快（有GPU时）

### 场景2: 专业翻译/字幕制作
**推荐**: 本地模式 + large-v2 模型（有GPU）或 API模式
- 最高精度
- 专业质量
- GPU加速可保证速度

### 场景3: 临时使用/测试
**推荐**: API 模式
- 无需下载模型
- 即开即用
- 适合偶尔使用

### 场景4: 移动办公/无网络
**推荐**: 本地模式 + base/small 模型
- 完全离线
- 笔记本电脑也能流畅运行
- 数据隐私保护

## 🐛 常见问题

### Q1: 本地模式启动失败，提示"faster-whisper 未安装"
**解决**:
```bash
pip install faster-whisper
```

### Q2: 本地模式首次使用很慢
**解答**: 首次使用需要下载模型文件（几分钟），后续使用会立即启动。

### Q3: 想要使用 GPU 但没有检测到
**检查**:
1. 确认安装了 NVIDIA 驱动
2. 确认安装了对应 CUDA 版本的 PyTorch
3. 运行 `python -c "import torch; print(torch.cuda.is_available())"` 检查

### Q4: 本地模型精度不如 API
**建议**:
1. 尝试使用更大的模型（如从 base 升级到 small）
2. 确保音频质量良好
3. API 模式使用的是更新的模型版本，某些情况下确实会更准确

### Q5: 可以同时安装两种模式吗？
**答**: 可以！安装完整依赖后，可在 GUI 中随时切换，无需重启程序。

### Q6: 模型文件可以删除吗？
**答**: 可以删除 `~/.cache/whisper/` 目录下的模型文件，下次使用时会重新下载。

## 📊 成本对比

### API 模式成本 (OpenAI Whisper API)
- 价格: $0.006 / 分钟
- 1小时音频: $0.36
- 每天1小时，一个月: ~$10.8

### 本地模式成本
- **软件成本**: 免费
- **硬件成本**:
  - CPU: 任意现代CPU即可
  - 内存: 8GB+ 推荐
  - 显存: 可选，2GB+ 可获得显著加速
  - 存储: ~500MB - 3GB（模型文件）

**结论**: 如果长期使用，本地模式可节省大量成本。

## 🔒 隐私说明

### API 模式
- 音频数据上传到 OpenAI 服务器
- 遵循 OpenAI 隐私政策
- 不建议用于敏感/保密内容

### 本地模式
- 所有数据在本地处理
- 无需上传任何内容
- 完全隐私保护
- ✅ **推荐用于敏感内容**
