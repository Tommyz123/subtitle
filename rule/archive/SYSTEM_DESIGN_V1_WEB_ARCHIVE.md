## ⚠️ 重要：架构已变更

**当前架构**: 本地桌面应用 (Local Desktop Application)

本文档原为 **Web应用架构设计 (v1.0)**，现已调整为 **本地桌面应用 (v2.0)**。

### 核心变更

| 原架构 (v1.0) | 新架构 (v2.0) |
|--------------|--------------|
| Web浏览器 + 麦克风输入 | **Windows桌面程序 + 系统音频捕获** |
| FastAPI + WebSocket | **Python + Tkinter GUI** |
| Redis会话管理 | **内存字典存储** |
| Docker + Kubernetes | **本地Python直接运行** |
| 多用户并发 | **单用户个人使用** |

### 新架构图 (v2.0)

```
[视频播放器 (VLC/Chrome/Netflix)]
            ↓
[Windows系统音频] → [VB-Cable虚拟音频设备]
            ↓
[PyAudio音频捕获线程] (48kHz立体声)
            ↓
[音频分块处理] (5秒/块)
            ↓
[OpenAI Whisper API转录]
            ↓
[DeepL API翻译]
            ↓
[Tkinter GUI显示双语字幕]
            ↓
[导出SRT/VTT字幕文件]
```

### 1.2 架构特点

| 特点 | 说明 | 优势 |
|------|------|------|
| **纯 API 架构** | 不依赖本地 GPU，使用云端 API | • 部署简单<br>• 成本可控<br>• 按需付费 |
| **异步处理** | 基于 asyncio 的并发管道 | • 高吞吐量<br>• 低延迟<br>• 资源高效 |
| **智能分段** | Silero VAD 语音活动检测 | • 节省 30-50% API 成本<br>• 自然语句边界<br>• 提高准确度 |
| **WebSocket 实时通信** | 全双工低延迟通信 | • 实时性好<br>• 双向推送<br>• 连接复用 |
| **无状态设计** | Redis 外部存储会话状态 | • 水平扩展<br>• 高可用<br>• 故障恢复 |

```python
# api/health.py
from fastapi import APIRouter, status
from datetime import datetime
import time

router = APIRouter(prefix="/api/v1", tags=["health"])

@router.get("/health")
async def health_check():
    """基础健康检查"""
    return {
        'status': 'healthy',
        'timestamp': datetime.utcnow().isoformat(),
        'version': '1.0.0'
    }

@router.get("/health/detailed")
async def detailed_health_check(
    redis: Redis = Depends(get_redis),
    whisper_client: WhisperAPIClient = Depends(get_whisper_client),
    deepl_client: DeepLAPIClient = Depends(get_deepl_client)
):
    """详细健康检查"""
    checks = {}
    overall_status = 'healthy'

    # 1. Redis 检查
    try:
        start = time.time()
        await redis.ping()
        redis_latency = (time.time() - start) * 1000
        checks['redis'] = {'status': 'up', 'latency_ms': round(redis_latency, 2)}
    except Exception as e:
        checks['redis'] = {'status': 'down', 'error': str(e)}
        overall_status = 'unhealthy'

    # 2. Whisper API 检查
    try:
        start = time.time()
        test_audio = generate_silent_audio(duration=0.1)
        await whisper_client.transcribe(test_audio)
        whisper_latency = (time.time() - start) * 1000
        checks['whisper_api'] = {'status': 'up', 'latency_ms': round(whisper_latency, 2)}
    except Exception as e:
        checks['whisper_api'] = {'status': 'down', 'error': str(e)}
        overall_status = 'degraded'

    # 3. DeepL API 检查
    try:
        start = time.time()
        await deepl_client.translate("test", target_lang="EN-US")
        deepl_latency = (time.time() - start) * 1000
        checks['deepl_api'] = {'status': 'up', 'latency_ms': round(deepl_latency, 2)}
    except Exception as e:
        checks['deepl_api'] = {'status': 'down', 'error': str(e)}
        overall_status = 'degraded'

    # 4. 系统资源检查
    import psutil
    cpu_percent = psutil.cpu_percent(interval=1)
    memory = psutil.virtual_memory()
    disk = psutil.disk_usage('/')

    checks['system'] = {
        'cpu_percent': cpu_percent,
        'memory_percent': memory.percent,
        'memory_available_mb': memory.available // (1024 * 1024),
        'disk_percent': disk.percent,
        'disk_free_gb': disk.free // (1024 ** 3)
    }

    # 5. 活跃连接数
    active_connections = await redis.scard('active_websocket_connections')
    checks['connections'] = {'active': active_connections, 'max': 50}

    return {
        'status': overall_status,
        'timestamp': datetime.utcnow().isoformat(),
        'checks': checks
    }
```

import logging
import json
from datetime import datetime

class JSONFormatter(logging.Formatter):
    """JSON 格式日志"""

    def format(self, record):
        log_data = {
            '@timestamp': datetime.utcnow().isoformat(),
            'level': record.levelname,
            'logger': record.name,
            'message': record.getMessage(),
            'module': record.module,
            'function': record.funcName,
            'line': record.lineno
        }

        if record.exc_info:
            log_data['exception'] = self.formatException(record.exc_info)

        if hasattr(record, 'extra_data'):
            log_data.update(record.extra_data)

        return json.dumps(log_data, ensure_ascii=False)

### 11.5 CI/CD 配置

#### GitHub Actions

```yaml
# .github/workflows/ci.yml
name: CI

on:
  push:
    branches: [ main, develop ]
  pull_request:
    branches: [ main, develop ]

jobs:
  test:
    runs-on: ubuntu-latest

    services:
      redis:
        image: redis:7
        ports:
          - 6379:6379

    steps:
      - uses: actions/checkout@v4

      - name: Set up Python
        uses: actions/setup-python@v4
        with:
          python-version: '3.11'

      - name: Install dependencies
        run: |
          pip install -r requirements.txt
          pip install -r requirements-dev.txt

      - name: Lint with flake8
        run: flake8 app tests

      - name: Type check with mypy
        run: mypy app

      - name: Security check with bandit
        run: bandit -r app

      - name: Run tests
        run: pytest --cov=app --cov-report=xml

      - name: Upload coverage
        uses: codecov/codecov-action@v3
        with:
          files: ./coverage.xml

  build:
    needs: test
    runs-on: ubuntu-latest

    steps:
      - uses: actions/checkout@v4

      - name: Build Docker image
        run: docker build -t transcription-app:latest .

      - name: Run Trivy vulnerability scanner
        uses: aquasecurity/trivy-action@master
        with:
          image-ref: transcription-app:latest
```
